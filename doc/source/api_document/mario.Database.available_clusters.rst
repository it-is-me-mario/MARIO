mario.Database.available\_clusters
==================================

.. currentmodule:: mario

.. autoproperty:: Database.available_clusters

Defaults are merged with stored user clusters. Regional cluster values retain
their region-to-list mappings, including explicit restrictions to a single
region. See :doc:`mario.Database.set_clusters` for the membership contract.

See :doc:`the clusters guide </user_guide/inspection/clusters>` for examples.

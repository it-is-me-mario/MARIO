mario.CoreModel.is\_chenerymoses
================================

.. currentmodule:: mario

The test reads native supply ``S`` when no unified ``Z`` or ``z`` view is
already materialized. Sparse supply values are reduced directly to regional
totals; only that small result is made dense. Region labels are compared
explicitly, so different row/column ordering or regional classification sizes
do not imply cross-border supply.
